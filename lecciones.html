Por qué dos métodos y no uno

No es que uno sea para los grandes y otro para el pequeño.

1

El silábico pide voz

Todo el método se apoya en decir el sonido y pegarlo al siguiente. Para un niño que habla es el camino más corto, porque después puede leer palabras que nunca ha visto.

2

El global no

La palabra se reconoce entera, como se reconoce una cara. Es la ruta de siempre para quien no puede producir sonidos, y no exige decir ni escribir nada.

3

Y tienen que cruzarse

El global solo sirve para las palabras que ya vio. El silábico sirve para todas. Por eso lo de Antonio arranca por global, pero no se queda ahí.

Cómo se usan las hojas de escritura

Se traza con el dedo en la pantalla o con el mouse: no hay que arrastrar nada. El primero de cada renglón está pintado — ese es el modelo, y conviene que usted lo pase primero delante del niño. El punto rojo dice dónde se pone el dedo y la flecha para dónde va.

La hoja no guarda nada, no corrige y no dice si está bien. Se borra y se vuelve a empezar.
